# Fonctionnalités de l’application

## 1. Rôle : Utilisateur (client)

- Créer un compte
- Se connecter
- Consulter les services disponibles
- Prendre un rendez-vous
- Voir ses rendez-vous
- Annuler un rendez-vous

---

## 2. Rôle : Employé

- Se connecter
- Voir les rendez-vous assignés
- Modifier le statut d’un rendez-vous (en attente, confirmé, terminé)

---

## 3. Rôle : Administrateur

- Se connecter
- Gérer les utilisateurs (CRUD)
- Gérer les employés (CRUD)
- Gérer les services (CRUD)
- Voir tous les rendez-vous
