## Frontend
- HTML 5
- CSS 3
- JavaScript
- Communication avec le backend via API REST (HTTP)

## Backend
- Node.js
- Express.js
- API REST
- Gestion de l’authentification
- Gestion des rôles (utilisateur, employé, administrateur)

## Base de données relationnelle
- PostgreSQL
- ORM : Prisma
- Stockage des utilisateurs, rendez-vous, services

## Base de données NoSQL
- MongoDB
- Stockage des logs et historiques d’actions

## Sécurité
- Authentification par JWT
- Hashage des mots de passe
- Middleware de protection des routes
